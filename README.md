# Персональный ИИ-ассистент для разработки 1С (локальный, без интернета)
## Описание
Локальный ИИ-ассистент на базе Ollama для написания, объяснения и отладки кода 1С:Предприятие 8.3. Полностью офлайн, без подписок. Клиент — Python-скрипт с живой потоковой выдачей ответа.
## Стек
| Технология | Назначение |
|------------|------------|
| Ubuntu 22.04 / 24.04 | ОС |
| Ollama (systemd-служба) | LLM-рантайм: автозапуск, режим CPU |
| Qwen3:8b | Основная модель |
| Python 3 + requests | Клиент со стримингом и обработкой ошибок |
| Git / GitHub | Версии и хостинг |
## Архитектура
- Служба `ollama.service` стартует при загрузке ОС; режим CPU закреплён в `/etc/systemd/system/ollama.service.d/override.conf` (`HIP_VISIBLE_DEVICES=-1` — обход зависания на AMD iGPU).
- Слушает 127.0.0.1:11434. Модели хранятся в `/usr/share/ollama/.ollama/models`.
- Клиент `chat_bot.py` (лежит в этом репозитории): стриминг токенов, обработка ошибок соединения и таймаутов.
## Установка с нуля
curl -fsSL https://ollama.com/install.sh | sh
sudo mkdir -p /etc/systemd/system/ollama.service.d
echo -e "[Service]\nEnvironment=\"HIP_VISIBLE_DEVICES=-1\"" | sudo tee /etc/systemd/system/ollama.service.d/override.conf
sudo systemctl daemon-reload
sudo systemctl enable --now ollama
ollama pull qwen3:8b
sudo apt install python3-requests
python3 ~/chat_bot.py
Сервер вручную запускать НЕ нужно — терминал полностью свободен.
## Заметки по использованию
- `daria@meow:~$` — терминал, `>>>` — приглашение бота. Не путать.
- Первый вопрос после включения — до минуты (модель 5 ГБ грузится в RAM), дальше быстро.
- Длинные ответы генерируются дольше коротких — норма для CPU.
- Модель может выдумывать функции 1С (`Вывод()` вместо `Сообщить()`) — ревью кода обязательно.
## Копилка опыта (проблема → решение)
| Проблема | Решение |
|----------|---------|
| Зависание на AMD iGPU | `HIP_VISIBLE_DEVICES=-1` в systemd override |
| `bash: !: event not found` | Файл через `cat << 'EOF'` |
| `pull`/`rm` виснут после прерванных закачек | `systemctl restart ollama`; план Б — stop + очистка `/usr/share/ollama/.ollama/models` |
| Бот пишет «Ошибка» | `journalctl -u ollama`: 404 на `/api/generate` = модель не докачана |
| Две папки моделей | Служба → `/usr/share/ollama/...`; лишняя `~/.ollama` (4.4 ГБ) удалена |
| Длинная вставка в терминал побила файл | Короткие чанки `cat << 'EOF' >>` + проверка `python3 -m py_compile` |
| «Молчащий» бот | Стриминг `'stream': True` — токены видны живьём |
| Галлюцинации API 1С | Ревью + системный промпт (см. роадмап) |
